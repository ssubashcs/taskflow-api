# TaskFlow API

A sample ASP.NET Core Web API for managing user-owned tasks.

## Features

- User registration
- Password hashing
- JWT login and authentication
- User-specific task access
- Task CRUD operations
- SQL Server LocalDB persistence
- Entity Framework Core migrations
- DTOs and validation
- Service-layer architecture
- Global error responses using Problem Details
- Structured logging
- Unit and API tests
- GitHub Actions CI

## Technology

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server LocalDB
- JWT Bearer Authentication
- xUnit
- GitHub Actions
